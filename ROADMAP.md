# Roadmap

## Now — proven vertical slice

- [x] Canonical meeting model and provenance.
- [x] Manual and signed Fathom intake.
- [x] Durable proposal queue with approval and rejection.
- [x] Obsidian Markdown outbox delivery.
- [x] Direct CRM adapter contract.
- [x] Minimal review workbench.
- [ ] Dogfood one real Fathom meeting into a quarantined Obsidian inbox.
- [ ] Add the Agent CRM meeting/activity endpoint and complete an end-to-end CRM delivery.

## Next — useful beyond one stack

- [ ] Fireflies signed webhook and transcript adapter.
- [ ] Granola/manual file adapter.
- [ ] Participant matching preview against CRM people and companies.
- [ ] Proposal editing before approval.
- [ ] Delivery retry queue and dead-letter view.
- [ ] Configurable retention and encrypted transcript storage.
- [ ] Source/destination capability discovery.

## Later — optional edges

- [ ] Generic outbound webhook adapter for n8n, Zapier, or custom consumers.
- [ ] Generic inbound canonical-event endpoint for trusted integration gateways.
- [ ] MCP read tools for agents to inspect meetings and pending proposals.
- [ ] Multi-workspace tenancy and OAuth installation flows.

## Explicit non-goals

- Recording meetings, joining calls, or competing with Fathom/Fireflies.
- Building a general visual automation canvas.
- Auto-writing to every connected system.
- Storing a universal private profile of the user.
